ملخص الإصدار الحالي (1.0)

  • تم إطلاق البنية الأساسية للمنصة مع التركيز على عمليات المسح الأساسية.
  • دمج أدوات مفتاحية: Nikto, Nmap, dirsearch, Nuclei, Subfinder.
  • واجهات المستخدم الأساسية لإدارة الحملات والنتائج جاهزة للاستخدام.
  • تم إنشاء آليات التقارير وتخزين النتائج مبدئياً.

خارطة طريق الإصدار 2.0

  1. إصلاح ودمج الأدوات غير الشغالة: SQLMap, Amass, Trufflehog, Subjack, XXEinjector, Burp/OWASP.
  2. دمج سلاسل أوامر متكاملة: تنفيذ مهام متسلسلة (discovery → scanning → exploitation) مع سجل تنفيذ قابل للمراجعة.
  3. تحسين النظام الإشعاري: إصلاح رسائل البريد الإلكتروني، وتمكين إضافة معرف الموظف فقط للبوت دون بيانات إضافية.
  4. تطوير صفحة الحملة: أزرار تخصيص إشعار الضحية (سماح/عدم السماح) مع سجل موافقات.
  5. تحسين قسم الشبكة: فحص أجهزة محسّن وإصلاح RouterSploit وMetaSploit ضمن sandbox آمن.
  6. اختبارات السحابة: ربط آمن مع AWS وGCP وAzure وتشغيل مسوحات أعمق.
  7. لوحات تقارير مخصّصة: إنشاء تقارير قابلة للطباعة وجدولة تقارير دورية للإدارة.
  8. قسم تحليل التطبيقات إصلاح مشكلة التحليل الديناميكي.

الخطوات التالية المقترحة

نقترح البدء بالأولوية: (1) Sandbox للأدوات الحساسة، (2) إصلاح تكامل SQLMap وAmass، (3) تحسين نظام الإشعارات.
